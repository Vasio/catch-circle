# Neon Arcade · Пэкмен

[Играть в Пэкмена](https://vasio.github.io/catch-circle/) · [Поймай кружок](https://vasio.github.io/catch-circle/circle.html)

Браузерная игра в стиле классической аркады: 150 точек, четыре призрака, три жизни, туннель, суперсила на 7 секунд и следующие уровни с растущей сложностью. Рекорд сохраняется в браузере. Звук включается отдельной кнопкой.

Управление: стрелки или WASD; пробел — пауза. На телефоне — кнопки под лабиринтом или свайпы по нему. При переходе в другую вкладку игра автоматически ставится на паузу.

`index.html` содержит всю игру без внешних зависимостей. Его можно открыть локально. GitHub Pages публикует корень ветки `main`.

Это самостоятельная любительская реализация с собственными кодом и графикой. `circle.html` сохраняет предыдущую игру.
